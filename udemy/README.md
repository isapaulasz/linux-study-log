## 📌 Sobre a plataforma

A **Udemy** é uma plataforma de cursos online em que instrutores independentes publicam cursos em vídeo sobre diversos assuntos, de tecnologia a negócios. Cada curso é organizado em seções e aulas, que podem ser assistidas no ritmo de cada aluno, o que facilita estudar aos poucos e rever o conteúdo quando necessário.

---

## 🗃️ Sobre o repositório

Esta pasta reúne os **cursos de Linux que fiz na Udemy**. Faz parte do repositório **linux-study-log**, onde registro meus estudos de Linux em diversas plataformas. Cada curso tem a sua própria pasta, com anotações pessoais das aulas e o registro do que foi estudado.

## 🗂️ Como organizo os diretórios

Uma pasta por curso, numerada na ordem em que foi feito, cada uma com o seu próprio README:

```
linux-study-log/
├── ...
└── udemy/
    ├── curso-linux-da-migracao-a-administracao/
    │   ├── secao-03-instalacao-do-linux.md
    │   ├── ...
    │   └── README.md
    └── README.md
```

Cada pasta de curso traz:

- 📋 README com a descrição do curso e o registro das seções
- 📝 Um arquivo de anotações por seção estudada
