# 🐧 Curso Linux: Da migração à administração do sistema operacional

</div>


## 📌 Sobre o curso

Curso da **Udemy**, do canal Toca do Tux, para aprender Linux com autonomia e confiança na administração do sistema. A proposta é explicar o sistema operacional em linguagem simples e preparar o aluno para as principais tarefas de administração e para a resolução de problemas.

**O que se aprende:**

- Diferenças entre as distribuições Linux e para qual público cada uma é destinada
- Principais tarefas de administração de um sistema Linux
- Administração do sistema com foco em encontrar a solução de problemas
- Habilidades básicas para um administrador Linux, alinhadas às certificações **LPIC-1** e **LFCS**

**Para quem é o curso:**

- Usuários e profissionais de Linux que querem aprofundar o conhecimento para certificações como LPIC-1 ou LFCS
- Usuários de Linux sem conhecimento técnico
- Usuários de Windows que querem entender o Linux para usar ferramentas como o Windows Subsystem for Linux (WSL), o WLinux (hoje Pengwin) e o Azure Sphere OS (Linux para IoT)
- Usuários e profissionais de Mac OS X que querem migrar para Linux, devido à similaridade
- Desenvolvedores que precisam entender o sistema operacional
