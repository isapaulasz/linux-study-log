# Seção 15 - Teclas de atalho

- `Ctrl + C`: interrompe um processo
- `Ctrl + Z`: pausa temporariamente o processo para liberar o terminal
- `top`: se assemelha ao gerenciador de tarefas do Windows
  - `q` (quit): sai do comando
- `!cp`: executa o último comando `cp`
- `Ctrl + R`: busca reversa no histórico; ao digitar, mostra o comando mais recente que contém o texto
- `Ctrl + P`: traz o comando anterior para a linha, semelhante a `!!`, mas permitindo editar antes de executar
- `Ctrl + S`: trava o terminal (pausa a exibição da saída)
- `Ctrl + Q`: destrava o terminal
- `Esc` seguido de `.` (ou `Alt + .`): insere o último argumento do comando anterior
- `Ctrl + Shift + T`: abre uma nova aba no terminal
- `Ctrl + A` e `Ctrl + E`: vão para o início e para o fim da linha
- `Ctrl + L`: limpa a tela
- `exit` ou `Ctrl + D`: fecha o terminal
