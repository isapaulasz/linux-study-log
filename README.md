## 🎓 Plataformas de estudo

### 🧑‍🏫 Udemy

A [**Udemy**](https://www.udemy.com) é uma plataforma de cursos online com videoaulas sobre diversos temas, ideal para aprender no seu ritmo e rever o conteúdo quando precisar.

📚 **Curso feito:** *Linux: Da migração à administração do sistema operacional*

📂 **Na pasta:** anotações de cada aula e os comandos e exercícios praticados durante o curso.

### 🏋️ Penguin Gym Linux

O [**Penguin Gym Linux**](https://penguin-gym-linux.com) é um terminal Linux online e gratuito para praticar comandos direto no navegador, sem precisar instalar nada. Ideal para quem está começando e quer ganhar fluência na linha de comando.

- 🌟 Terminal interativo com exercícios do nível iniciante ao avançado
- 🌟 Quizzes e artigos para reforçar o que foi praticado
- 🌟 Ótimo para fixar comandos como `pwd`, `ls`, `cd`, permissões e gerenciamento de processos

📂 **Na pasta:** anotações dos exercícios e os comandos praticados em cada trilha.
